B TEAM · SLACK APP GUIDE

Slack App 建置指南

第三版。補完前版缺的 Install 安裝步驟(這是最容易卡死的一步),並把實際踩過的坑寫成警告。目標:建好 Alice、成功安裝、拿到 xoxb- token、確認頻道 @ 得到。

這份只涵蓋 Slack 這一側,終點是「Bot 已安裝、能被 @、拿到 token」。接 GAS endpoint 是下一份的事。

0環境前置檢查(最重要,先做)

⚠ 先確認這件事,否則做到最後一步會全部卡死 Slack 免費方案的 workspace 最多只能裝 10 個 App。如果你要裝的 workspace 已經滿 10 個,不管前面設定多正確,最後 Install 那步一定失敗,跳出「無法新增更多應用程式」。這不是設定錯,是額度問題。
先確認怎麼查
要裝哪個 workspace?技術驗證 → 用新開的空 workspace;正式給團隊用 → 團隊所在的 workspace
那個 workspace App 額度還夠嗎?workspace 名稱 → 工具與設定 → 管理應用程式,數數看幾個
你有安裝權限嗎?企業 workspace 可能要 admin 核准才能裝 App
本次情境 你已另開一個新的空 workspace 做技術驗證 → 全新 10 個額度,不會卡。但記得:新 workspace 只有你自己,團隊 @ 不到 Alice,只能測試用。正式上線得另外處理。

B標示說明

必做選做跳過
  • 必做 不做 Bot 跑不起來
  • 選做 依情境,先不做也 OK
  • 跳過 這次用不到

1選對 Workspace,建 App

1
開 Slack API 主控台
必做
api.slack.com/apps
先搞懂:舊 App 不會自動搬到新 workspace 如果你之前已經在別的 workspace(例如公司的)建過一個 Alice,那個 App 是綁死在原 workspace 的,沒辦法搬。要在新 workspace 用,得重新登入新 workspace、重建一個新的 Alice。舊的那個放著不管或之後刪掉都行。下面的步驟就是重建流程。
2
切換到正確的 Workspace
必做
這時畫面應該是:「Your Apps」列表,列出你現有的 App(每列顯示 App Name / Workspace / App ID)。
找畫面最底部的藍字：Sign in to another workspace
位置別找錯 切 workspace 的入口不是左上角(那個下拉是進到某個 App 內部後才有)。在 Your Apps 列表頁,入口是整個列表最下方的藍字「Sign in to another workspace」。點它 → 登入你新開的 workspace。
怎麼確認切對了:切換後,之後 Create App 對話框的 Workspace 下拉裡,要出現你新開的 workspace 名字可選。
3
Create New App → 選 Blank app
必做
Your Apps 頁右上角的綠色按鈕：Create New App
點下去會跳出對話框「Create new app」,有四個選項(Slack 改版後從「兩選項」變成「四選項」,別被嚇到)。逐一說明如下,你要選 Blank app。
選項是什麼該不該選
AI agent Slack 官方的 AI 助理範本,預先接好 Bolt 框架 + 某個 agent SDK(Claude/OpenAI),假設你要自架 Node/Python 伺服器跑 AI agent ❌ 不選。它綁一整套框架,跟你「GAS 收事件」的路線不合,選了要拆
Starter app 用 Bolt 搭的最小範本,含 App Home、私訊、@mention 幾個進入點的範例程式碼 ❌ 不選。雖然含 @mention 聽起來對,但一樣綁 Bolt 框架,不走 GAS
From a manifest 用一份 YAML/JSON 設定檔,一次把 scopes、events、bot 名字全帶完 △ 進階。手動點清楚就好,重複建很多個或要版控設定時才用得上
Blank app 空殼,什麼都沒預裝。所有設定(scope、event、名字)你自己手動加 ✅ 選這個。跟 GAS 路線相容,也是舊版「From scratch」的等價物
對話框底部還有一行「Prefer using the terminal? Slack CLI」 那是叫你用命令列工具建 App,一樣綁 Bolt/CLI 框架,忽略它。你走網頁點選 + GAS 就好。
一句話:前三個都預設「你有自己的伺服器」,只有 Blank app 讓你自由接 GAS Web App。選 Blank app → Continue / Next。
4
填名字、選 Workspace、Create
必做
App name: Alice(之後可改)
Workspace: 下拉選新開的那個(再次確認別選到舊的)
Workspace 選了不能改 這個綁定終身,選錯只能刪 App 重建。看清楚再按 Create。
建完怎麼確認選對:回到 Your Apps 列表,會看到兩個 Alice——一個 Workspace 是舊的、一個是新開的。認明 Workspace 欄位是新 workspace 的那個,才是要用的。

2加權限(Scopes)

為什麼先加 Scope 新版介面下沒加 scope,App Home 的 Bot 設定會被鎖住(灰色點不了)。所以順序上先加 scope。
1
進 OAuth & Permissions
必做
左側 Features → OAuth & Permissions
2
找到 Scopes 區塊
必做
在 OAuth & Permissions 頁往下捲(要捲一段，會經過 Redirect URLs 等區塊)
捲到標題「Scopes」就對了。底下分上下兩塊：
區塊用途你要用嗎
Bot Token Scopes
(機器人權杖權限範圍)		Bot 自己的權限✅ 加在這裡
User Token Scopes
(使用者權杖權限範圍)		以真人身分操作 API❌ 不要碰
兩塊長很像,別加錯 一定加在上面那塊 Bot Token Scopes。加到下面的 User Token Scopes 是無效的。
3
加這兩個 Scope
必做
在 Bot Token Scopes 那塊,點 Add an OAuth Scope,搜尋並加入這兩個:
Scope作用
app_mentions:read收到「有人 @ 它」的事件
chat:write讓 Bot 能發訊息
加好的樣子:兩個 scope 會列在 Bot Token Scopes 底下,各自一行。加了即時生效,不用按儲存。
4
Restrict API Token Usage(IP 白名單)
跳過
同頁下方的 IP 限制,不要碰。
為什麼:GAS 出口 IP 浮動,設了白名單會讓 GAS 呼叫 Slack 全被擋。

3設定 Bot User

1
進 App Home
必做
左側 Features → App Home
已加好 scope → 看到「Your App's Presence in Slack」區塊,可以設名字了,往下做。
還沒加 scope → 看到綠色按鈕「Review Scopes to Add」、Show Tabs 開關是灰的。點綠按鈕去加 scope(回階段 2),加完回來就解開。
2
設 Bot 名字(App Display Name → Edit)
必做
Your App's Presence in Slack 區塊 → App Display Name 右邊 Edit
欄位填什麼規則
Display Name
顯示的名字		Alice可含大小寫、中文
Default Name
@ 打的 handle		f2e-alice全小寫、無空白
撞名會加編號 若已有人用 alice,系統自動變 alice2。想明確是 bot 就取 f2e-alice。
3
開 Always Show My Bot as Online
必做
為什麼:不開會顯示灰色離線,別人以為壞了。開了永遠綠點。
4
Messages Tab 的勾選項
選做
Show Tabs → Messages Tab 可開,但底下「Allow users to send Slash commands and messages...」先不要勾。
為什麼不勾:勾了會開放私聊輸入,但你只訂了頻道 @ 事件、沒訂私訊事件,使用者打字 Bot 不會回,體感更差。

4Install 安裝(最關鍵)

⚠ 這步是整個流程的關鍵開關 前面設定再完整,沒按 Install,Bot 就不存在於 workspace——@ 不到、invite 不了、沒有 token。上次就卡在這。
怎麼判斷「還沒裝」:看這兩個訊號其中一個就是還沒裝——
· Install App 頁是綠色 Install 按鈕(不是 token)
· Basic Information 頁顯示 0 authed users
（注意:App Home 的「Bot Token Added」字樣會誤導,那不代表已安裝）
1
進 Install App 頁
必做
左側 Settings → Install App
2
按 Install to [你的 workspace]
必做
會看到一段字「OAuth Tokens will be automatically generated when you finish installing」+ 綠色按鈕 Install to [workspace 名]。按它。
你會看到:如果這頁顯示的是綠色 Install 按鈕(而不是 token),就代表之前根本沒裝。這是正常的,按下去就對了。
3
授權頁按「允許」
必做
這時畫面應該是:標題「允許 F2E-Alice 應用程式存取 Slack」的授權頁。逐項確認:
畫面欄位要確認什麼
Workspace顯示正確的 workspace 名(例如 104 F2E,不是舊的 104 Corp)
可以採取的動作
「在頻道與對話中執行動作」		這對應你加的 chat:write,正常。這就是 Bot 能發訊息的權限
右上「管理權限」不用點。那是給你細調權限用的,預設就對
確認 workspace 對 → 按綠色 允許。
可能遇到的兩種攔阻 ① 額度滿:跳「無法新增更多應用程式 / 已達 10 個上限」→ 這 workspace App 滿了,換 workspace 或砍舊 App。(新開的空 workspace 不會遇到)

② 要 admin 核准:企業 workspace 若開核准機制,按下去變「送出申請」,要找 admin 批准。

5取得 Token

1
複製 Bot User OAuth Token
必做
Install App 頁(安裝後會變樣)→ Bot User OAuth Token 安裝成功後,這頁會出現 xoxb-... 開頭的 token。按 Copy 複製。
你會看到:頁面從「綠色 Install 按鈕」變成「一串 xoxb- token + Copy 按鈕」。看到 token 就代表真的裝好了。
Token 保管 別貼進聊天室、別 commit 進 git。存到密碼管理器或之後放 GAS Script Properties。
2
順便拿 Signing Secret / Verification Token
選做
Basic Information → App Credentials 接 GAS 時會用到(驗證請求來自 Slack)。現在拿或之後拿都行。

6邀請 Bot 進頻道

裝好、有 token 了,但頻道還 @ 不到 —— 因為還沒邀請進頻道。裝好 ≠ 自動進所有頻道。
1
開一個測試頻道
必做
建 #alice-test 之類的頻道自己測。
2
用自動完成邀請(關鍵技巧)
必做
在頻道輸入框,照順序做:
1. 打 /invite (含空格)
2. 打 @,慢慢輸入 alice(打顯示名,不是 f2e)
3. 浮出清單,找帶「應用程式 / App」標籤 + 綠點那個
4. 滑鼠點它,讓 @alice 變藍色(這步最重要)
5. 送出
兩個一定要知道的雷 ① 一定要從清單點選,不能手打。手打的 @f2e-alice 是純文字,Slack 不認,會回「需要有效的成員名稱」。從清單點選才會變藍色 mention。

② 打顯示名不是 handle。清單用 Display Name(alice)過濾,不是 handle(f2e-alice)。所以打 @alice 找得到,打 @f2e 可能找不到。

7確認能被 @

1
試 @ 它
必做
頻道打 @alice hello。
✅ 打 @ali 有浮出 Alice 建議
✅ 送出後 @alice 顯示為藍色可點(不是黑色純文字)
Bot 不會回應是正常的 —— 還沒接 endpoint。重點是 @ 得到、顯示藍色,代表 Slack 這側全對。

8完成檢查表

  • 確認過目標 workspace App 額度沒滿
  • App 建在正確的 workspace(沒選錯)
  • Bot Token Scopes 加了 app_mentions:read、chat:write
  • App Home 設好 Display Name / Default Name
  • Always Show My Bot as Online 已開
  • Install App → Install to workspace → Allow 已完成
  • Install App 頁看到 xoxb- token(不是綠色 Install 按鈕)
  • Token 已複製保管
  • 用自動完成清單(藍色 mention)invite 進測試頻道
  • @alice 顯示藍色可點

十項全打勾 = Slack 這側完成,可以接 GAS endpoint 了。

9踩過的坑(血淚整理)

坑真相 / 解法
設定全對,最後裝不進去免費方案 10 App 額度滿。換 workspace 或砍舊 App
「Bot Token Added」以為裝好了那是誤導。要 Install App 頁按安裝、看到 xoxb- token 才算
Basic Info 顯示 0 authed users= 還沒真的安裝。回 Install App 頁按安裝
/invite @f2e-alice 說「需要有效成員名稱」手打的是純文字。要從自動完成清單點選變藍色
打 @f2e 找不到 bot自動完成用 Display Name(Alice)過濾,改打 @alice
App Home 看不到 Bot 名字設定Scope 沒加。先加 scope 才會解鎖
清單出現不認識的 App 名App name 和 Bot Display Name 是不同欄位,可能顯示舊值。以 Basic Info 的 App name 為準

10哪些設定不用碰

選項為何跳過
Socket Mode你有 GAS Web App URL,走 HTTP 就好
AgentsSlack AI agent 框架,綁 Bolt/CLI
Incoming Webhooks單向推播,你要雙向
Interactivity & Shortcuts按鈕/表單 UI 才需要
Slash Commands想做 /alice 指令再開
MCP Servers方向相反的新功能,現在不用
Manage Distribution公開發佈或跨 workspace 才用
Collaborators多人共同開發才用

11常見問題

Install App 頁只有綠色按鈕,沒有 token?

代表還沒安裝。按綠色 Install 按鈕 → Allow,之後才會生成 token。

按 Install 跳「無法新增更多應用程式」?

這個 workspace 免費額度(10 App)滿了。換 workspace 或移除一個舊 App。

要 admin 核准怎麼辦?

企業 workspace 的核准機制。送出申請後找 Slack 管理員批准。

invite 一直失敗?

九成是手打純文字。務必從 @ 自動完成清單點選,讓它變藍色 mention 再送出。

新 workspace 團隊看不到 Alice?

正常。Bot 只在它安裝的 workspace 內有效。新測試 workspace 只有你,團隊要用得裝到團隊所在的 workspace。

介面中英混雜?

Slack 中文化沒做完,忽略即可,不影響操作。
